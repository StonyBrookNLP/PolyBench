Answer

Task 2 · Conceptual Knowledge

Question

Explain the difference between step-growth and chain-growth polymerization.

Answer

Step-growth involves monomers with multiple reactive groups forming bonds incrementally, while chain-growth proceeds via initiation, propagation, and termination through active centers.

Task 5 · Advanced Property Reasoning

Question

Given that COc1cc(C=CC(=O)c2ccc(C)cc2C)ccc1O has a Bertz complexity index of 699.6 and contains 12 aromatic carbons, which structural features contribute most significantly to its molecular complexity?

Answer

The complexity arises primarily from two differently substituted aromatic rings — one bearing methoxy and hydroxyl groups and the other bearing methyl groups — connected by an α,β-unsaturated ketone. This arrangement creates an extended conjugated system with multiple substitution patterns.

Task 6 · Design & Synthesis

Question · retrosynthesis

Which monomers produce *Nc1c(Br)cc(C(=O)OC)cc1NC(=O)OC1CS(=O)(=O)CC1OC(*)=O through condensation?

Answer

Monomer 1: O=C(Cl)OC1CS(=O)(=O)CC1OC(=O)Cl
Monomer 2: COC(=O)c1cc(N)c(N)c(Br)c1

Question · open-ended design

Design a polymer with a glass transition temperature (Tg) between 80–100 °C using CC(CCC(=O)O)C(=O)O and CC(C)(O)c1c(O)cccc1Br as monomers, while maintaining chain flexibility for processing. The polymer must retain bromine functionality for post-polymerization modification.

Reasoning & answer
  1. Constraints: Tg 80–100 °C, flexibility, retain –Br.
  2. Diacid → flexibility; aromatic diol → rigidity.
  3. Balance segments to hit Tg while preserving mobility.
  4. Position Br away from reactive sites.
  5. Condensation via –OH groups forms ester linkages.

Alternating units of the brominated aromatic ring connected via ester linkages to flexible aliphatic segments. *Oc1cccc(Br)c1C(C)(C)OC(=O)CCC(C)C(*)=O

# PolyBench

**Teaching and Evaluating LLMs to Reason About Polymer Design Related Tasks**

Dikshya Mohanty, Mohammad Saqib Hasan, Syed Mostofa Monsur, Size Zheng, Benjamin Hsiao,
Niranjan Balasubramanian — Stony Brook University

*To appear in EACL 2027*

🌐 [Project page](https://stonybrooknlp.github.io/PolyBench/)

PolyBench is a large-scale training and test benchmark of more than 125K polymer
design-related tasks, built on a knowledge base of over 13 million experimental and synthetic
polymer data points and augmented with knowledge-grounded chain-of-thought traces. Models with
7B–32B parameters trained on PolyBench outperform similar-sized baselines and remain
competitive with closed-source frontier LLMs.
